# zcode-plugins

[简体中文](README.md) | [English](README_EN.md)

My ZCode plugin marketplace, maintained by mojianjjun.

## Plugins

| Plugin | Version | Description |
|--------|---------|-------------|
| [db-connector](./db-connector) | 0.1.2 | Read-only access to MySQL / PostgreSQL / MongoDB: multi-environment connections, parameter-bound safe queries and schema browsing |

## Add this marketplace

1. Open ZCode → **Plugin Marketplace**
2. Click **Add → Add Plugin Marketplace**
3. Paste this repository URL: `https://github.com/mojianjjun/zcode-plugins`
4. After validation, install the plugin under **Personal → zcode-plugins**
