|------|------|------|
| [db-connector](./db-connector) | 0.1.2 | 只读连接 MySQL / PostgreSQL / MongoDB：多环境多连接配置、参数绑定安全查询与结构浏览 |

## 添加本市场

1. 打开 ZCode → **插件市场 / Plugin Marketplace**
2. 点击 **添加 / Add → 添加插件市场 / Add Plugin Marketplace**
3. 粘贴本仓库地址：`https://github.com/mojianjjun/zcode-plugins`
4. 校验通过后，在 **个人 / Personal → zcode-plugins** 中安装插件
